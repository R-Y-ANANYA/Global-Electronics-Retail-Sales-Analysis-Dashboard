📌 Project Overview

This project analyzes retail sales data to understand sales performance across products, regions, customers, and time.

The project follows an end-to-end analytics workflow, starting with data cleaning and validation, followed by SQL analysis, data modeling, Power BI development, and business-focused dashboard reporting.

 🎯 Business Objective

The objective of this project is to transform raw retail sales data into meaningful business insights that can help stakeholders understand:

* Overall sales performance
* Sales trends over time
* Regional performance
* Product performance
* Customer-related patterns
* Key business KPIs

 🛠️ Tools & Technologies

* Microsoft Excel
* SQL
* Power Query
* Power BI
* DAX

 🔄 Analytics Workflow

1. Data Cleaning
2. Data Validation & Quality Assessment
3. Data Transformation
4. SQL-Based Analysis
5. Data Modeling
6. DAX Measure Development
7. Dashboard Development
8. Business Analysis & Reporting

 🧹 Data Preparation

The dataset was prepared for analysis by performing data cleaning and quality checks.

Key preparation activities included:

* Identifying missing values
* Checking duplicate records
* Reviewing data quality
* Correcting data inconsistencies
* Transforming data into an analysis-ready structure
* Preparing fields required for reporting

 🗂️ Data Modeling

A **Star Schema** data model was designed in Power BI to organize the data and support efficient analysis.

The model separates relevant business dimensions and measurable sales information to support reporting across different analytical perspectives.

 📊 Power BI Dashboard

The final Power BI solution contains dashboards designed for different stakeholder perspectives:

 Executive Dashboard

Provides a high-level view of business performance and key KPIs.

 Regional Dashboard

Focuses on sales performance across different regions.

 Operational Dashboard

Provides more detailed information for analyzing sales and operational performance.

 📈 Key Analysis Areas

The analysis focuses on:

* Sales trends
* Regional performance
* Product performance
* Customer insights
* Business KPIs

 🧮 DAX

DAX measures were created to support business analysis and KPI reporting.

The project uses DAX for calculations required to evaluate sales performance and provide interactive reporting within Power BI.

 💡 Business Value

The dashboard transforms raw retail data into an interactive reporting solution that allows stakeholders to explore performance from multiple perspectives.

It demonstrates how data cleaning, validation, modeling, analysis, and visualization can be combined into an end-to-end business intelligence workflow.
